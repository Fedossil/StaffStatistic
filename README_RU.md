**StaffStatistic** — это модульный и готовый к продакшену плагин для администрирования, контроля смен и учета активности игрового персонала Minecraft-серверов (**1.16.5 – 1.21+**). 

Плагин автоматизирует контроль за работой состава, отслеживает чистое рабочее время на смене, динамически выдает и снимает права через LuckPerms, а также экспортирует статистику в Discord и Google Таблицы.

---

## ✨ Ключевые возможности

* 🕒 **Режим рабочей смены (`/staffwork` / `/sw`):**
  * Точный учет времени дежурства (игнорирует обычное игровое время и AFK).
  * Автоматическая выдача прав при выходе на смену и моментальное снятие при завершении или выходе с сервера.
* 🖥️ **Интерактивное графическое меню (`/staff`):**
  * Отображение реальных голов скинов сотрудников с сортировкой по приоритету должностей.
  * Индикаторы онлайн-статуса (`[● ОНЛАЙН]` / `[● ОФФЛАЙН]`).
  * Управление персоналом в один клик: выдача предупреждений, выговоров, очистка нарушений и снятие с должности.
* ⚖️ **Система наказаний:**
  * Команды: `/staff warn <ник> [причина]` и `/staff rebuke <ник> [причина]`.
  * Индивидуальные лимиты предупреждений и выговоров для каждой роли с автоматическим снятием при превышении.
* 📊 **Интеграции и логирование:**
  * **LiteBans / AdvancedBan:** Подсчет количества выданных сотрудником банов и мутов.
  * **Discord (Вебхуки):** Информативные Embed-уведомления о смене статуса дежурства и выданных наказаниях (`discord.yml`).
  * **Google Таблицы:** Автоматический экспорт сессий, онлайна и нарушений через Google Apps Script (`sheets.yml`).
* 🌐 **Локализация (i18n):**
  * Полная поддержка UTF-8 и отдельных файлов локализации в папке `locale/` (`ru_RU`, `en_US`) с поддержкой HEX-градиентов (`&#RRGGBB`).

## 📋 Команды и права

| Команда | Описание | Право доступа |
| :--- | :--- | :--- |
| `/staff` | Открыть главное GUI-меню управления персоналом | `staffstatistic.admin` |
| `/staffwork` (алиас `/sw`) | Начать или завершить рабочую смену | `staffstatistic.work` |
| `/staff add <ник> <роль>` | Назначить игрока на должность стаффа | `staffstatistic.admin` |
| `/staff kick <ник>` | Снять сотрудника с должности | `staffstatistic.admin` |
| `/staff up <ник> <роль>` | Повысить сотрудника на указанную роль | `staffstatistic.admin` |
| `/staff down <ник> <роль>` | Понизить сотрудника на указанную роль | `staffstatistic.admin` |
| `/staff warn <ник> [причина]` | Выдать предупреждение сотруднику | `staffstatistic.admin` |
| `/staff rebuke <ник> [причина]` | Выдать строгий выговор | `staffstatistic.admin` |
| `/staff stats <ник>` | Показать детальную статистику сотрудника в чате | `staffstatistic.admin` |
| `/staff createnew <роль> <приоритет>` | Создать новую должность прямо в конфиге | `staffstatistic.admin` |
